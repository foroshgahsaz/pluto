# راهنمای سامانه تحریریه

مخاطب: خبرنگار، ویراستار، سردبیر

## گردش کار خبر
`پیش‌نویس → در حال بررسی → تأیید/رد → انتشار فوری یا زمان‌بندی → منتشر شده → بایگانی`

از وضعیت «تأیید شده»، دکمه **انتشار فوری** خبر را بلافاصله منتشر می‌کند؛ **زمان‌بندی انتشار** برای آینده است.

| نقش | کارهای اصلی |
|-----|-------------|
| خبرنگار | ایجاد/ویرایش پیش‌نویس، ارسال برای بررسی |
| ویراستار | بررسی، تأیید/رد با دلیل |
| سردبیر | انتشار، زمان‌بندی، ویژه/منتخب، مدیریت دسته/برچسب |

## نکات
- خبر سایت A برای کاربر سایت B دیده نمی‌شود
- انتشار زمان‌بندی‌شده با جاب هر دقیقه انجام می‌شود
- تصاویر شاخص از کتابخانه رسانه؛ فایل خصوصی فقط با مجوز دانلود

## مشاهده عمومی
پس از انتشار: `/{site}/news/{slug}` و RSS در `/{site}/rss.xml`
