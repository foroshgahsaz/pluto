# 17 — API Documentation

## Policy
No public or partner HTTP API is approved for MVP beyond what Filament/Livewire requires internally.

When an API is explicitly approved later, document:

- Authentication
- Authorization / site isolation
- Endpoints
- Rate limits
- Versioning
- Examples

## Current status
**No custom REST/GraphQL API implemented or approved.**

Internal routes (Filament, Livewire, future authorized media download) are application routes, not a public API surface.
